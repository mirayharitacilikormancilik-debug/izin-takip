# İzin Takip

İzin dosyalarının hangi aşamada ve nerede olduğunu büro, çalışanlar ve müşterilerle birlikte takip etmek için uygulama.

Uygulama adresi: https://mirayharitacilikormancilik-debug.github.io/izin-takip/

Telefona kurmak için adresi açıp tarayıcı menüsünden **Uygulamayı yükle** (iPhone'da **Paylaş › Ana Ekrana Ekle**) seçin.
